# Archive

These documents are **not normative**. They are design notes, plans, and reviews from earlier phases. Some are out of date.

If an archive document and a requirement disagree, the requirement is correct. See [Principles](../principles.md) and [Requirements](../requirements/README.md).

Use these documents for background and detail only. Examples:

- Hardening plans: `apple-silicon-hardening.md`, `linux-hardening.md`, `windows-hardening.md`
- Formal analysis: `formal-model.md`, `billing-and-caching.md`, `matching-algorithm.md`
- Earlier specs: `requirements.md`, `product-spec.md`, `alpha-system-design-spec.md`
